## 2026-07-16 - Next.js App Router Performance Optimizations
**Learning:** Large statically imported libraries (like `html2canvas-pro` and `jspdf`) significantly bloat the initial client bundle and delay the Page Interactive (LCP/TBT) times, even when they are only utilized for localized user actions (like a download PDF button). By on-demand importing them dynamically via ES6 `import()` within the download handler, initial chunk size is slashed, and the resources are downloaded lazily on demand. Additionally, caching HTTP model discovery payloads (using Next.js `{ next: { revalidate: 3600 } }`) prevents Vercel function invocation stalls, and component memoization prevents parent component file updates from causing full sub-tree updates.
**Action:** Always dynamically load client-only dependencies that are not needed on initial load, and leverage next fetch caching for critical third-party API discovery steps.
